# 赫萝的货币兑换所 · 《狼与香辛料》主题站

一个个人同人站点：外壳是一张**铺在桌上的中世纪商路地图**，里面装的是
**「1 元人民币能在大模型 API 与订阅套餐里换到多少 token」**——罗伦斯管账，赫萝管换算。

> 本站为非官方粉丝作品，与原作、动画制作委员会及文中提到的各家厂商均无隶属关系。

🔗 **线上站点**：<https://heik-nymph.github.io/spice-and-wolf-web/>

---

## 站上有什么

网站按「商路」串起来：首页是一张自南向北的地图，从南方的帕斯罗村出发，
沿商路北上直到北方森林里的约伊兹。沿途每个驿站都是一块能进去的板块。

### 旅途回忆录（首页）
一张按行商路线画的地图，铺在木桌上。桌面上还随手搁着账本、香料袋、银币、一束麦穗和几张画片 ——
**这些也能点**，分别通向账本、牌价板和画坊。

- **拖动**：按住地图平移；**缩放**：滚轮，或手机上双指捏合；右下角有 ＋ / − / 全览。
- 点驿站会先亮起来、下方站牌换成那一站的说明；**再点一次才进去**（手机上尤其如此，避免误触）。
- 右上角「驿站目录」可以直接跳到任意一站。

### 商行 · 牌价板
输入一个金额，看各家的 token 牌价：**输入 / 输出 / 缓存命中分列**，
官方按量 API、聚合平台、订阅套餐各有自己的算法。

- 美元与人民币的汇率**可以自己填**，改完全站数字实时重算。
- 可以把感兴趣的几家「加入对照」，图表并排比。
- 每张牌价卡下面都写着数据来源链接和核对日期。

### 旅途账本
记各家 API 的结余：金额类的看剩余 / 赠送 / 充值，比例类的看各时间窗用量，
每条都带最近核对时间。可以一条条「核对」，也可以「全部核对」。

### 旅伴 · 人物图鉴 / 语录集
按驿站看人物与旅途片段，底部有「上一站 / 下一站」。

### 画坊 · 绘图工作台
挑角色（赫萝 / 罗伦斯 / 缪莉，参照 2024 重制版设定）、写场景、选尺寸与质量，然后出画片。

- 可以**上传参考图**、在画面上**框选裁剪**、以当前那张为底**整张重绘**；
- 生成历史在下方一字排开，可以点开、重命名、删除；
- 含角色的图会按「角色 + 场景」的规则约束服装与画面，避免出成现代装。
- 这块是**桌面工具**：边上三块面板要并排摊开，竖屏手机上会提示你换到电脑。

## 数据从哪来

| 内容 | 来源 |
| --- | --- |
| 牌价 | 人工从各家官方公开页面录入，**非实时行情**，可能滞后或有误，请以官方页面为准 |
| 账本余额 | 由各厂商公开接口查询，仅供参考，请以各厂商官方账单为准 |
| 汇率 | 手工填写，不自动更新 |
| 画片 | 由 AI 图像模型生成 |

## 你的东西存在哪

站点**不收集、不上传**任何个人信息，也没有账号体系。

线上部署的是**纯前端单机版**：没有后端，所有交互都在你自己的浏览器里完成。
汇率、账本条目、画坊历史这类改动只写在你本机浏览器（localStorage）里：

- 换一台设备 / 换一个浏览器 / 清掉浏览器数据，这些改动就会一起消失；
- 账本页有一个「恢复示例账目」，可以把账页恢复成随站点带来的样子。

## 关于两个版本

本仓库同时包含两套实现，共用同一份界面代码：

- **单机版**（线上就是这个）：纯静态前端，数据与交互全部在浏览器里完成，不需要任何服务。
- **服务端版**：多一个本机 Node 服务，牌价读本地 JSON、账本可去厂商接口核对、画坊会真的调用图像模型出图。

## 想自己跑一份

```bash
npm ci
npm run dev          # 服务端版本（需要自己填 .env，见 .env.example）
npm run dev:pages    # 单机版（不需要任何密钥）
```

`npm run build:pages` 会生成可以直接丢给 GitHub Pages 的静态产物。
